
# My_Q_bot

Бот для игры в квиз


## Creator

- [@mike_F0](https://github.com/RapidMovement/-mike_F0)


## Documentation

database.py - файл содержащий асинхронные функции для работы с базой данных.

quiz_data.py - файл содержащий вопросы квиза.

My_Quiz_ziuQ_bot_script.py - файл содержащий основные функции бота для telegramm.

test.py - файл содержащий команды для просмотра содержимого базы данных.

quiz_bot.db - база данных бота содержащая id пользователей и результаты игры.
